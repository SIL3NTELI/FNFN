# Battle Royale - Season 1 (browser fan project)

Three.js battle royale: 30 players (you + 29 AI bots), battle bus, glider drop, looting, pump/AR/pistol with rarities, wood harvesting, wall/floor/ramp building, shrinking storm, minimap, kill feed.

## Run
Open `index.html`, or serve locally: `python3 -m http.server 8000` then visit http://localhost:8000

## Controls
WASD move, Shift sprint, Space jump / leave bus, Mouse aim + fire, 1-4 slots, R reload, E loot, Q wall, F floor, C ramp.

Unofficial fan project. Not affiliated with Epic Games.
